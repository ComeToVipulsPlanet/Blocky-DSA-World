# Assets Directory

This directory is reserved for application assets, icons, and genuine screenshots.

## Screenshot Suggestions for GitHub:
1. `screenshot_overview.png`: Full application view showing both Stack and Queue loaded with colorful 3D blocks.
2. `screenshot_animation.png`: Mid-animation shot showing a block sliding or dropping into place.
3. `screenshot_learning_mode.png`: The Learning Mode dialog displaying LIFO/FIFO walkthrough and viva quiz.
4. `screenshot_error_handling.png`: Friendly validation messages for stack underflow / queue empty states.

All visual graphics (3D blocks, voxel scenery, trees, clouds, avatar mascot) are rendered directly and procedurally on the Tkinter Canvas using native Python standard library primitives.
